# AI求职面试助手使用流程

## 1. 启动项目

进入项目目录：

```powershell
cd ai-career-interview-assistant
```

安装依赖：

```powershell
python -m pip install -r requirements.txt
```

启动 Streamlit：

```powershell
streamlit run app.py
```

浏览器打开：

```text
http://localhost:8501/
```

## 2. 配置 DashScope

如需调用 DashScope 大模型，先设置 API Key：

```powershell
$env:DASHSCOPE_API_KEY="你的 DashScope API Key"
streamlit run app.py
```

项目代码按要求使用：

```python
dashscope.api_key = os.getenv("DASHSCOPE_API_KEY")
```

不设置 API Key 也可以运行，系统会自动切换为离线演示或本地检索模式，并在页面提示当前状态。

## 3. 侧边栏演示流程进度

页面左侧会显示 `演示流程进度`，用于答辩时控制展示节奏：

1. 简历分析
2. 面试题库
3. 模拟面试
4. 岗位匹配
5. 就业数据
6. 竞争力分析

完成对应操作后，侧边栏会显示当前流程状态，便于按顺序演示。

## 4. 简历优化

入口：`简历优化`

可操作点：

1. 选择目标岗位。
2. 上传简历文本文件，支持 `txt` 和 `md`。
3. 或直接在文本框粘贴简历内容。
4. 点击 `一键填入测试简历`，快速填入演示用简历。
5. 点击 `分析简历`。
6. 分析完成后点击 `导出优化建议`，下载 Markdown 格式的优化建议。

输出结果：

- 简历匹配度。
- 技能标签云。
- 简历优化建议。
- 后续 `岗位匹配` 和 `竞争力分析` 会使用这里生成的简历画像。

可选目标岗位：

- 产品经理
- 数据分析师
- 金融分析师
- AI应用开发
- 后端开发工程师
- 商业分析师
- 风控专员
- 运营专员
- 市场营销专员
- 会计审计专员
- 法务专员

## 5. RAG 面试题库

入口：`面试题库`

可操作点：

1. 查看 `当前RAG模式` 状态标签。
2. 在输入框输入岗位或行业面试问题。
3. 点击 `快速检索回答`。
4. 或点击 `AI润色回答（qwen3.7-plus）`。

当前模式标签包括：

- `本地快速检索`
- `qwen3.7-plus 可选润色`
- `在线模型可用` 或 `离线演示模式`

输出结果：

- RAG 面试题库回答。
- 来源引用。
- 离线或本地检索模式提示。

推荐测试问题：

```text
数据分析师 SQL 面试会问什么？
AI应用开发面试会问什么？
金融分析师常见面试题有哪些？
产品经理如何回答用户需求分析题？
法务专员面试会问什么？
```

说明：

- `快速检索回答` 默认使用本地知识库，速度更快。
- `AI润色回答（qwen3.7-plus）` 会在配置 API Key 后调用 DashScope 大模型。
- 未配置 API Key 时，会显示 `离线演示模式`，并使用本地检索或离线回答兜底。

## 6. 模拟面试

入口：`模拟面试`

使用前建议先完成 `简历优化`。

可操作点：

1. 选择模拟岗位。
2. 点击 `开始/重置面试`。
3. 根据面试官问题输入回答。
4. 点击 `提交本轮回答`。
5. 如果上一轮回答不满意，点击 `重新回答上一轮`。
6. 如果不想等满 5 轮，点击 `结束面试并生成报告` 查看阶段性报告。
7. 完成 5 轮回答后自动查看最终报告。

输出结果：

- 每轮即时点评卡片。
- 点评卡片包含观察和改进建议。
- 已回答轮次。
- 阶段性报告或最终评分报告。
- 多维度评分雷达图。
- 岗位匹配度环形图。

评分机制说明：

- 正常结构化中文回答会得到较高分。
- 输入 `12345`、`随便`、`不知道`、`asdf` 等低质量回答会触发低分。
- 大部分回答无效时，总分会被压到极低区间。

## 7. 岗位匹配

入口：`岗位匹配`

使用前必须先完成 `简历优化`。

可操作点：

1. 查看系统推荐的岗位列表。
2. 查看每个岗位的匹配度。
3. 查看薪资区间。
4. 展开 `本地岗位详情`。
5. 点击 `查看本地岗位详情`，在页面底部展示稳定的本地岗位说明和补强路径。
6. 点击 `查看学习路径`。
7. 点击 `查看岗位参考`，作为可选外部搜索参考。

答辩建议：

- 优先展示本地岗位详情，不依赖外网。
- 外部岗位参考链接只作为补充材料。

输出结果：

- 岗位推荐排序。
- 匹配技能。
- 待补强技能。
- 本地岗位说明。
- 个性化学习路径。
- 预测薪资范围。

## 8. 就业数据 Text2SQL

入口：`就业数据`

可操作点：

1. 点击常用问题快捷按钮。
2. 或在自然语言查询框输入问题。
3. 点击 `生成SQL并查询`。

快捷问题包括：

- `各学院就业率排名`
- `法学院本科就业率`
- `不同行业薪资对比`
- `哪些岗位薪资最高`

输出结果：

- 自动生成的只读 SQL。
- 查询解释。
- 数据表格。
- 折线图、柱状图等可视化结果。

推荐测试问题：

```text
法学院本科就业率
金融学院和会计学院就业率对比
各学院就业率排名
数据分析师近两年薪资变化
法务专员近两年薪资变化
不同行业薪资对比
哪些岗位薪资最高
有哪些岗位可以投递
```

数据说明：

- 就业率数据来自中南财经政法大学官方就业质量报告。
- 薪资数据参照国家统计局社会平均工资，并按岗位常见行业映射。
- 薪资不是学校官方薪资，也不代表具体企业录用薪资。
- Text2SQL 只允许执行 `SELECT` 查询，避免误删或修改数据库。

## 9. 竞争力分析

入口：`竞争力分析`

使用前必须先完成 `简历优化`。

可操作点：

1. 查看简历-岗位匹配度环形图。
2. 查看个性化学习路径。
3. 查看竞争力雷达图。
4. 如果在 `岗位匹配` 中点击过某岗位的 `查看学习路径`，这里会展示对应岗位的补强建议。

输出结果：

- 简历岗位匹配度。
- 个性化学习计划。
- 技能匹配、项目表达、行业理解、面试准备等维度分析。

## 10. 推荐完整演示流程

1. 打开系统首页。
2. 查看左侧 `演示流程进度`。
3. 进入 `简历优化`，点击 `一键填入测试简历`，选择 `AI应用开发`，点击 `分析简历`。
4. 查看匹配度、技能标签云和优化建议，点击 `导出优化建议`。
5. 进入 `面试题库`，查看 `当前RAG模式`，输入 `AI应用开发面试会问什么？`，点击 `快速检索回答`。
6. 进入 `模拟面试`，选择岗位，提交 1-2 轮回答后演示 `重新回答上一轮`，再点击 `结束面试并生成报告`。
7. 进入 `岗位匹配`，点击 `查看本地岗位详情`，展示本地岗位说明和学习路径，再展示可选外部参考链接。
8. 进入 `就业数据`，点击快捷问题 `法学院本科就业率`、`不同行业薪资对比`、`哪些岗位薪资最高`。
9. 进入 `竞争力分析`，展示最终个人提升路径和雷达图。

## 13. 常见问题

### 没有配置 API Key 能不能运行？

可以。系统会自动切换到离线演示或本地检索模式。

### 为什么薪资只是参考？

项目中的薪资数据参照国家统计局社会平均工资，并按岗位常见行业映射，不代表学校官方薪资，也不代表具体企业录用薪资。

### 为什么岗位参考还有外部搜索页？

本地岗位详情已经可稳定展示，外部搜索页只是补充参考，用于查看更多真实招聘描述。

### 模拟面试乱输为什么分数很低？

系统已经加入低质量回答识别和熔断机制。纯数字、无意义字符、过短回答会被判定为低质量回答。
